Предмет: Обработка и генерация изображений

Лабораторная работа №1 

Цель проекта — решить задачу классификации изображений с помощью сверточной нейронной сети.
Модель получает на вход изображения и предсказывает, к какому из 10 классов относится каждый объект.

Определение типа одежды (FashionMNIST)

Модель обучается на тренировочной выборке и оценивается по метрикам Accuracy, Precision, Recall и F1-score на валидационных данных.

Описание:

Используется набор данных из 10 классов изображений.

Все изображения приводятся к размеру 224x224 и нормализуются.

Пример для Fashion-MNIST

60 000 изображений (32×32 px)

50 000 — обучение, 10 000 — тест

EfficientNet-B0 показала высокое качество классификации при сравнительно небольшой сложности.

Основное влияние на результат оказывают:

качество и баланс классов в датасете,

количество эпох,

параметры обучения (lr, augmentations).

 Метрики (в среднем по всем классам) 
Accuracy:  0.9469
Precision: 0.9471
Recall:    0.9469
F1-score:  0.9466
