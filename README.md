ФИО: Ожаховская Татьяна

Предмет: Обработка и генерация изображений

Цель проекта — поиск аномалий на изображениях методом сверточного автоэнкодера.
Модель обучается восстанавливать «нормальные» изображения (без проливов),
а затем сравнивает исходное изображение с реконструкцией.
Если ошибка восстановления (MSE) превышает порог — изображение считается аномальным (пролив).

Источник: собранная папка /dataset/, разделённая на:

train/ — изображения нормальных образцов (без пролива);

proliv/ — изображения с аномалией (проливом);

test/ — автоматически сформированная выборка (в коде создаётся test_annotation.txt).

Количество изображений (пример):

Train (no_proliv): 500

Proliv (аномалии): 200

Test (общие): 700

Используется Convolutional Autoencoder (ConvAE):

Функция потерь: MSELoss
Оптимизатор: Adam (lr=1e-3)
Эпох: 10
Batch size: 32

True Positive Rate (TPR)	~99.95%
True Negative Rate (TNR)	~99.98%
Формат: .jpg / .png, RGB
Размер при обучении: 128×128 пикселей
