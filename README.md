ФИО: Ожаховская Татьяна

Предмет: Обработка и генерация изображений

Цель эксперимента — проверить, улучшает ли комбинированная дистилляция (KL + MSE по фичам) качество студента по сравнению с обычным обучением.
Идея - провести несколько экспериментов, например:
Добавить MSE между фичами студента и учителя, чтобы студент перенял структуру внутренних представлений.
Замедлить обучение студента (например, уменьшить lr), чтобы он лучше следовал распределениям учителя.
Добавить несколько уровней дистилляции, чтобы студент учился на разных уровнях абстракции.

Метрики acc по экспериментам
Baseline Student 0.736
Эксперимент 1 0.7939
Эксперимент 2 0.7655
Эксперимент 3 0.7781
Комбинированная дистиляция 0.7616

Общие выводы:

Logit KD даёт лучший прирост, так как содержит оптимальную и богатую информацию о распределении вероятностей учителя.

Feature KD улучшает качество, но не так сильно, поскольку не содержит сигнал о классах.

MSE KD с регрессором даёт приличный прирост, но чуть хуже логитной KD.

Комбинированная KD не дала синергии — возможно, из-за конфликта лоссов и сложностей в балансировке.
